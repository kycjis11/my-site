# 사이트 설계도(PRD) — (가게 이름 미정) 시즌 낚시용품

작성일: 2026-10-10 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
시즌별로 유행하는 낚시용품을 보여 주고, 주말 낚시꾼에게 맞는 장비를 추천해 주는 낚시용품 가게 소개 사이트.

## 2. 손님
- 누가: 주말 낚시꾼. 계절마다 노리는 어종에 맞춰 장비를 바꾸는 취미 낚시인
- 어디서 알고 오나: 인스타그램, 네이버 검색·블로그, 낚시 카페·밴드, 지인 소개·단골

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 이번 시즌에 어떤 장비를 추천하는지 (지금 계절·어종에 잘 나가는 것)
2. 가격 (장비 가격대·세트 가격)
3. (미정)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 직접 찍은 장비·매장 사진
- 조황·조과 사진 (사장님·손님이 잡은 고기)
- 낚시 경력·가게 운영 기간: (숫자 미정 — 사장님이 직접 알려 줄 때까지 비워 둠)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 장비 추천 문의
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + 버튼(장비 추천 문의)
2. 이번 시즌 추천 장비 — 계절·대상 어종별 인기 용품과 가격대
3. 믿을 증거 — 장비·매장 사진, 조황·조과 사진, 낚시 경력·운영 기간(미정)
4. 후기 자리 (비워 둠)
5. 문의 폼 + 가게 정보(위치·영업시간·연락 방법 — 미정)

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 대상 어종·출조지 (어디서 무엇을 낚을지)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가게 이름: (미정)
- 가격: (미정 — 추천 장비별 가격은 사장님 확인 후 넣기)
- 영업시간: (미정)
- 위치: (미정)
- 연락 방법: (미정)
- 낚시 경력·운영 기간: (미정)

## 9. 이번에 넣지 않을 것
- 온라인 결제·장바구니
- 회원가입·로그인
- 손님 사진 올리기
- 알림 메일
- 재고 실시간 표시, 미리 챙겨두기(예약) 기능

## 10. 첫 화면 한 문장 후보
1. 이번 주말 출조, 지금 계절에 맞는 장비부터 챙기세요.
2. 계절이 바뀌면 채비도 바뀝니다. 이번 시즌 장비를 골라 드려요.
3. 어디서 무엇을 낚을지 알려 주시면, 맞는 장비를 추천해 드립니다.

## 11. 다음에 할 것
- 가게 이름·위치·영업시간·연락 방법·운영 기간 채우기 (만들기 전에)
- 시즌 추천 장비 목록과 가격 정리
- 실제 후기가 생기면 후기 자리에 넣기
- 재고 문의·예약, 온라인 판매는 필요해지면 다시 검토

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
